PoseCanvas is a course research project about **body poses, prop placement, and anime-style image generation**. It brings together report visuals, pose-processing utilities, a Visual Context Adapter, and skeleton-weighted loss modules, alongside the original FLUX image-generation demos.

> **Current scope:** the custom pose-conditioned training and inference scripts are research scaffolds, with integration still to complete. The gallery is taken from the report, not generated by running the current checkout. The Gradio and Streamlit demos run the base FLUX workflow. [See what is implemented →](docs/research-status.md)

## Research design

The idea is to describe **where the body and props should be**, then use text to describe the scene. A skeleton encoder produces visual feature tokens; a spatially weighted loss gives additional weight to skeleton and prop regions during training.

## Try the base FLUX demo

Use **Python 3.10+** and a CUDA-capable GPU. The commands below launch the inherited FLUX demos, not the unfinished custom pose pipeline. Model weights and text encoders are large; `--offload` reduces GPU residency but still needs substantial system memory. No fixed minimum VRAM is claimed.

### Install

```bash
git clone https://github.com/masktrump19-sudo/posecanvas.git
cd posecanvas
python -m venv .venv
```

Activate the environment with `source .venv/bin/activate` on Linux/macOS or `.venv\Scripts\Activate.ps1` in Windows PowerShell.

Install a compatible PyTorch build for your machine using the [official installation instructions](https://pytorch.org/get-started/previous-versions/). The repository targets PyTorch 2.6.0; for a compatible CUDA 12.4 setup:

```bash
python -m pip install torch==2.6.0 torchvision==0.21.0 --index-url https://download.pytorch.org/whl/cu124
python -m pip install -e ".[gradio,streamlit]"
```

The root `requirements.txt` is a historical environment snapshot with platform-specific CUDA and ComfyUI packages; it is not the recommended cross-platform setup path.

### Launch

```bash
# Gradio: base text-to-image demo
python demo_gr.py --name flux-schnell --offload

# Streamlit: choose a base model in the interface
streamlit run demo_st.py -- --offload=True
```

For FLUX.1-dev, use `--name flux-dev` in the Gradio command after obtaining access to the [official model](https://huggingface.co/black-forest-labs/FLUX.1-dev). The base demo also exposes image-to-image options for supported models; this is separate from skeleton conditioning.

The scripts download missing model files from Hugging Face. To use existing local weights, set `FLUX_MODEL` and `FLUX_AE` to the corresponding files before launch. Automatic downloads are stored under `checkpoints/<repository_name>/`. A model license and, for gated models, an authorized Hugging Face account are required. Keep tokens out of code and commits.

Gradio stays local unless `--share` is explicitly added. These commands have been checked against the source interfaces; a full GPU inference run was not performed as part of this documentation refresh.
